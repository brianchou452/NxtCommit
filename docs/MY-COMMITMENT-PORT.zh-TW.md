# My Commitment 整合

[English](MY-COMMITMENT-PORT.md)

NxtCommit 既有的貢獻者頁面現在採用 commoncommit 完整個人頁呈現。目的地是既有 `/contributors/:id` 路由與 Cloudflare 應用，並非另一個網站或資料庫。

來源：commoncommit `a52346519fa7258a56ec39f70212b243d599e833` 的 `src/pages/Profile.tsx`、`src/components/BadgeShelf.tsx`、成就元件與後端規則。目標基準為 NxtCommit `397adcd`，並整合 main `02986b0` 的首頁文案與 Agent Lab 導覽更新。本次整合工作位於 `codex/my-commitment-port` 分支。

## 行為與資料

- 個人資訊、頭像、錢包、認捐額度與聲望沿用既有人物。五項統計會區分未量測歷史與真正的零。
- 13 種徽章皆有中英文；收藏將已獲得徽章依最早日期排列於前，包含等級邊框、分類色彩、未解鎖說明與獲得日期。成就卡片依徽章分組，顯示次數與最近日期。
- 收據連到實際任務，呈現認捐、消耗、退款、審查產物、本機發布與有來源標記的選用採用數據。認捐歷史提供相同任務連結、狀態、額度及相對日期。
- 保留載入骨架、404 復原、網路重試、渲染錯誤復原與三個空白區塊。共用 SSE 任務事件與重新連線會更新個人頁。雙語與響應式版型沿用現有導覽框架。
- 任務服務仍是唯一錢包／帳本權威。個人頁透過既有 detail 介面讀取資料，以確定性整數分攤消耗，並包含審核前已發生的退款。混合舊歷史與實測資料時會明示部分統計。讀取個人頁不寫入成就或帳務資料。
- 認捐成就依已儲存的認捐順序、達標、UTC 時間與專案廣度計算。發布成就需要既有發布／成就日期；文件成就需要產物路徑證據；AI Architect 需要真正 LLM／Codex 執行。舊 `ship` 轉為 `ship_it`。整合資料中的 `usedByYou` 只表示曾支持，不能用來證明依賴關係。
- NxtCommit 尚無實測發布採用數據或上游套件發布機制。未知採用量、未量測示範帳務與缺少的發布版本保持缺省，不複製來源專案的示範數字。已有本機示範發布／成就仍保留來源標示。本次是介面與讀取模型整合，不是新增登入、付款或獨立後端。

## 設計檢查

實作前檢查設計系統 YAML、個人頁／元件／API／視覺規格與兩張匯入的 approved golden。元件與 API 規格已更新為完整徽章目錄、五项統計與事件刷新行為。

底色、字體、語意色、圓角與陰影沿用 NxtCommit tokens。桌面邊距 24px；緊湊個人頁間距參照來源。等級邊框與分類圖示色彩分離。桌面順序為個人資訊 → 統計 → 收藏 → 成就 → 收據 → 認捐。既有導覽／首頁／圖解不在本次頁面修改範圍。

桌面截圖已按結構與匯入來源 golden 比對。人物、統計、成就數量、導覽與來源說明因目標後端／種子資料不同而保留差異；原 golden 不變，不宣稱像素基準已核准。手機視覺基準尚未涵蓋：390px 繁中截圖、溢出與鍵盤操作檢查是本次證據，並非已核准的手機 oracle。Docker 瀏覽器設定亦檢查減少動態效果模式。

## 驗證與發布

驗證以 Docker 固定 Node 24 環境為準。首輪應用檢查通過型別、正式建置與 168 項後端測試；初次瀏覽器測試發現需調整支援 SSE 的錯誤 fixture 與翻譯文字斷言。本機執行因 npm 阻擋安裝腳本而無法載入 better-sqlite3；Docker 明確重建該套件後相關測試通過。

最終本機 Docker 驗證通過全部 168 項後端測試及 49 項互動瀏覽器流程，包含跨頁認捐刷新與重新載入持久性。131 份規格檢查零錯誤；合併 main 後型別及 0.7.31 版本檢查通過。發布證據記錄於交接。桌面／手機截圖保留於 Docker 測試產物。正式發布須通過既有 CI、操作員備份，以及獨立比對 HTTPS `/__deployment` SHA。Cloudflare 仍使用暫存 SQLite；備份是離線復原副本，並非自動還原。回滾需以相同流程重建先前已驗證版本。
