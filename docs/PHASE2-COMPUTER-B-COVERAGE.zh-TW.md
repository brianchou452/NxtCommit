# 電腦 B / Phase 2 coverage 計畫

[English](PHASE2-COMPUTER-B-COVERAGE.md)

狀態：B demo-only 功能已獨立 verified；細部 coverage 限定保留如下；visual equality 未核准。此 YAML 驗收清單連結既有證據，不宣稱每個細部 assertion 都已測試。34 個自有 specs、30 個具名 scenarios、13 個 approved visual baselines；原始英文 outcome 保留以便與 canonical YAML 逐字追溯。

## Scope 與整合依賴

B 擁有 mission lifecycle、funding、execution、queue、對應 API/components/pages。以 `skills/yaml-spec-to-code/references/three-computer-phases.md` 為準，不套用舊產品 roadmap 的 Phase 2 定義。

A 擁有 design-system、home-demo-seed、global i18n、root React router、migration registry、central BDD entrypoint、Playwright config 與 reset orchestration。B 交付 locale fragments 與接線需求，不藉此實作 A。C 擁有 project explanation/model-assistance、reviewability/evidence 共用契約的消費端；B 提供 ExecutionEvidenceReader。

Mission detail 的 explanation（C）與 comment wall（A）是跨 owner 依賴：B 必須驗證局部失敗、retry 與 stale-response isolation，但本文件不把 A/C endpoint 實作列為 B 交付。公開 metadata 不可執行；只允許 copied bundled fixture。

每個 page scenario 另須 Docker Playwright 真實 build 的 UI journey；server BDD、TODO、screenshot-only 不能替代。以下測試路徑是 spec 指定或 planned，不代表已新增或已通過。
