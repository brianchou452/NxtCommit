# 由審查回饋累積的儲存庫流程

首頁分開呈現本次任務修正與儲存庫流程演進兩個迴圈。九階段互動示例
串起既有流程、根因與影響、驗收、程式、測試、審查、修正、流程更新、下一個議題。

單次按鈕顏色意見不是永久規範。鍵盤示例保留候選規則的留言來源、儲存庫與
表單適用範圍、版本及可執行驗收要求。播放不會確認規則，使用者必須另外按下
明確標示為模擬的維護者確認，才展示 v2 與下一個議題新增的關卡。重設回到 v1。

本次實作是產品呈現，不是真實審查回覆擷取或規則引擎。確認按鈕不儲存正式規則，
不代表維護者身分驗證，也不會替匯入的儲存庫安裝鍵盤測試關卡。串接已授權的
審查回饋、不可變的規則版本歷史，以及由執行引擎判定的後續任務關卡，仍待實作。
頁面明確顯示此邊界；代理實驗室的真實執行證據保持獨立。

驗證包含雙語字典、型別與建置，以及瀏覽器的鍵盤確認、待確認與已確認狀態、
重設、中文導覽和手機無橫向溢出。此次重新設計沒有覆寫既有核准視覺基準圖。
